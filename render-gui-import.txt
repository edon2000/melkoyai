Render Database GUI Import Guide
=================================

EASIEST METHOD - Use Render's Built-in SQL Console:

STEP 1: ACCESS DATABASE CONSOLE
1. Go to Render Dashboard: https://dashboard.render.com
2. Click on your database: "melkoyai-db"
3. Look for one of these options:
   - "Connect" tab
   - "Query" button
   - "SQL Console" 
   - "Database Console"
   - "Open in Browser"

STEP 2: OPEN SQL EDITOR
- Render provides a web-based SQL editor
- No installation required
- Works directly in your browser

STEP 3: IMPORT SCHEMA
1. Open supabase-schema.sql in text editor
2. Copy ALL contents (Ctrl+A, Ctrl+C)
3. Paste into Render's SQL console
4. Click "Run" or "Execute"

STEP 4: VERIFY SUCCESS
- Check if tables were created
- Run: SELECT * FROM users LIMIT 1;
- Should show your database structure

ALTERNATIVE: RENDER SHELL ACCESS
Some Render plans provide shell access where you can:
1. Access database via built-in terminal
2. Run psql commands directly
3. Import files using \i command

BENEFITS OF GUI METHOD:
✅ No command line needed
✅ No psql installation required
✅ Visual feedback on execution
✅ Easy error checking
✅ Copy-paste friendly

IF GUI NOT AVAILABLE:
- Use external tools like pgAdmin
- Use online PostgreSQL clients
- Install psql locally and use command line
