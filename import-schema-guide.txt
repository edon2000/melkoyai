================================================================

STEP-BY-STEP INSTRUCTIONS:

1. OPEN TERMINAL/COMMAND PROMPT
   - Windows: Open Command Prompt or PowerShell
   - Mac/Linux: Open Terminal

2. NAVIGATE TO YOUR PROJECT FOLDER
   cd /path/to/your/elonmusk/folder
   (Make sure you're in the folder that contains supabase-schema.sql)

3. IMPORT SCHEMA DIRECTLY (ONE COMMAND):
   PGPASSWORD=9CSOkDxcQz0zg0wmWNFaIikPrtVoYHgg psql -h dpg-d5ao3vqli9vc73ba9380-a.oregon-postgres.render.com -U melkoyai_db_user -d melkoyai_db -f supabase-schema.sql

   This command will:
   - Connect to your Render database
   - Execute all SQL commands in supabase-schema.sql
   - Create all tables, indexes, and data

4. VERIFY IMPORT SUCCESS:
   After import, connect to check tables:
   PGPASSWORD=9CSOkDxcQz0zg0wmWNFaIikPrtVoYHgg psql -h dpg-d5ao3vqli9vc73ba9380-a.oregon-postgres.render.com -U melkoyai_db_user -d melkoyai_db

   Then run: \dt
   You should see all your tables listed.

ALTERNATIVE METHOD (If above doesn't work):

1. CONNECT TO DATABASE:
   PGPASSWORD=9CSOkDxcQz0zg0wmWNFaIikPrtVoYHgg psql -h dpg-d5ao3vqli9vc73ba9380-a.oregon-postgres.render.com -U melkoyai_db_user melkoyai_db

2. IMPORT FILE FROM PSQL PROMPT:
   \i supabase-schema.sql

3. OR COPY-PASTE METHOD:
   - Open supabase-schema.sql in text editor
   - Copy all contents
   - Paste into psql prompt
   - Press Enter

EXPECTED RESULT:
- All tables created (users, products, transactions, etc.)
- Sample data inserted
- Database ready for application use

TROUBLESHOOTING:
- If "psql command not found": Install PostgreSQL client
- If connection fails: Check if database is running in Render dashboard
- If permission errors: Verify username/password are correct
